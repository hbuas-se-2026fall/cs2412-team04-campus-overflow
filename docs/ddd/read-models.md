## 一、角色清单（6 个）

| 角色 | 权限范围 | 说明 |
|---|---|---|
| 访客 | 浏览公开问题列表、搜索、查看公开问题详情 | 未登录；课程问题不可见（403 QA-3006） |
| 学生（STUDENT） | 提问、回答、评论、投票、加入课程 | 课程问题仅课程成员可见 |
| 助教（TA） | 课程内教师认证、发起悬赏、管理课程成员 | 课程内细粒度角色，全局 RBAC 为 `TA` |
| 教师（TEACHER） | 课程内教师认证、发起悬赏、管理课程成员、创建课程 | 课程内细粒度角色 |
| 管理员（ADMIN） | 账号认证、角色调整、创建教职工账号、全局管理 | 唯一全局管理员 |
| 定时任务 | 悬赏过期回收、浏览量落库、会话清理等 | 系统内部角色，无 UI |

> v1.1 候选：原版「版主」未实现；如后续需要内容治理角色再引入。

## 二、外部系统清单（2 个）

| 外部系统 | 谁调用它 | 失败时怎么降级 |
|---|---|---|
| MySQL 8.0.39 | 全量持久化 + ngram 中文全文检索 | 数据库故障即不可用，靠健康检查与重启恢复 |
| Redis 7 | 会话（Spring Session）、限流、浏览量计数、排行榜 ZSET | 会话失效需重新登录；限流/计数/榜单降级或延迟 |

> v1.1 候选（原版误列，实际未实现）：邮件服务、OAuth 登录、对象存储、独立搜索服务。
> 搜索目前是 MySQL ngram 全文索引（ADR-005），不是外部搜索服务；@提及通知为站内通知，不依赖邮件。

## 三、读模型（7 个）

| 读模型名 | 服务的界面 | 关键字段 | 数据来源 |
|---|---|---|---|
| 问题列表 | 问题列表页 / 搜索页 | 问题ID、标题、摘要、标签、回答数、票数、浏览数、是否已采纳 | 问题 + 回答计数 + 投票 + 搜索投影 |
| 问题详情 | 问题详情页 | 正文、回答列表、每答票数、是否已采纳、评论（含二级回复）、我的投票、权限 | 问题 + 回答 + 投票 + 评论 + 用户 |
| 课程列表 | 课程页 / 我的课程页 | 课程ID、编号、名称、学期、教师、我的角色 | 课程 + 成员关系 |
| 排行榜 | 排行榜页 | 排名、用户、认证标记、分数（周/月/学期/总榜） | Redis ZSET + 声誉账户 |
| 声誉主页 | 声誉页 | 声誉值、可用/冻结积分（仅本人）、徽章墙、积分流水 | 声誉账户 + 流水 + 徽章 |
| 通知中心 | 通知页 | 通知列表（分页）、未读数 | 通知记录 |
| 搜索结果 | 搜索页 | 匹配问题列表、关键词命中、相关标签 | 搜索索引（MySQL ngram 投影） |
