## 一、角色

| 角色 | 权限范围 |
|---|---|
| 访客 | 浏览公开问题、搜索、查看公开问题详情 |
| 学生（STUDENT） | 提问、回答、评论、投票、加入课程 |
| 助教（TA） | 课程内教师认证、发起悬赏、管理课程成员 |
| 教师（TEACHER） | 课程内教师认证、发起悬赏、管理课程成员、创建课程 |
| 管理员（ADMIN） | 账号认证、角色调整、创建教职工账号、全局管理 |
| 定时任务 | 悬赏过期回收、浏览量落库、会话清理 |

> v1.1 候选：问题「收藏」未实现。

## 二、外部系统

| 外部系统 | 调用方 | 失败降级 |
|---|---|---|
| MySQL 8.0.39 | 全量持久化 + ngram 中文全文检索 | 数据库故障即不可用，靠健康检查与重启恢复 |
| Redis 7 | 会话、限流、浏览量计数、排行榜 ZSET | 会话失效需重新登录；限流/计数/榜单降级或延迟 |
