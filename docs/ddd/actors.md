# 角色与外部系统

> 负责人：青岑（Dev-1）
> 口径：与当前代码 `Role` 枚举、课程成员角色和 Spring Security 配置一致。

## 一、角色

| 角色 | 权限范围 |
|---|---|
| 访客（未登录） | 浏览公开问题与课程列表/排行榜，搜索公开问题；课程问题详情/相关问题不可见；不能写 |
| 学生（STUDENT） | 登录、加入课程；在课程内提问/回答/评论/投票；公开问题可直接参与；可采纳自己问题的回答 |
| 助教（TA） | 学生权限 + 课程内容管理（含发起悬赏、采纳、认证）；课程成员角色为 TA |
| 教师（TEACHER） | 学生权限 + 课程内容管理（含发起悬赏、采纳、认证） |
| 管理员（ADMIN） | 全局管理：认证学生、创建教职工、改角色、禁用账号；可管理所有内容（含任意课程悬赏/采纳/认证） |
| 定时任务 | 悬赏到期退款、声誉对账；不是可登录角色 |

> v1.0 问题可见性：未挂课程的公开问题对所有访问者可见；课程问题仅 ADMIN、作者、课程成员可见。未加入课程的访问者看到“无权限”引导。

> W-06 决策（2026-11-25）：未挂课程的公开问题没有课程归属，全局 TEACHER/TA **不自动获得管理权**——公开问题仅作者本人或 ADMIN 可编辑/删除/采纳/认证（`IdentityApiImpl.canManageCourse` 对 `courseId == null` 的非管理员返回 false）。TEACHER/TA 的课程管理权限仅在其为对应课程的教师/助教成员时生效；该口径与指导书 2.5.2「未关联课程时全局教师亦可」为有意偏离，记录见 `docs/reports/v1-scope-decisions-2026-11-25.md`。

## 二、外部系统

当前实现没有邮件服务、OAuth、对象存储或独立搜索服务：

| 能力 | 实际实现 | 失败降级 |
|---|---|---|
| 登录/注册 | 学号/工号 + 密码（Spring Security + Spring Session） | 无第三方登录 |
| 搜索 | MySQL `ngram` 全文索引 + `dis_search_doc` 投影 | 投影未完成时可能暂时搜不到，不阻断主流程 |
| 通知 | 站内 `dis_notification` 表 | 事件重试；无外部推送 |
| 文件/图片 | 未实现上传，问题/回答只存 Markdown 文本 | 不支持附件 |

> “邮件服务 / OAuth / 对象存储 / 搜索服务”是早期规划，不属于 v1.0 实现，不得写入验收证据。
