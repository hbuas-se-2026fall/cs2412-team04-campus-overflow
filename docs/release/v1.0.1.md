## 1. 本版修复

| 类别 | 修复 |
| --- | --- |
| 会话安全 | 登录 Session principal-name 索引改为规范名；禁用账号撤销按规范名查找；新增 `ActiveUserFilter`，被禁用旧会话访问任意已认证接口返回 401 |
| 字段密钥 | `CO_FIELD_MAC_KEY` 真正生效，AES/HMAC 分离；缺省 HKDF 派生；`FieldEncryptor` 拒绝 AES=MAC；prod 拒绝 dev 公开密钥/默认密码/demo |
| 部署 | 生产 compose 默认 `prod`、不暴露 3306/6379、密钥全必填；新增 `docker-compose.dev.yml` 与 `.env.example` |
| 发件箱 | 严格按 id 顺序处理；失败后后续行租约延长到同一重试时间，避免投影乱序 |
| 分页/限流 | `PageRequest.offset()` 改 long + 页上限；登录限流读取 `window-seconds`，旧无 TTL key 自动补 PEXPIRE |
| 其他 | 浏览量落库失败回填 PENDING；排行榜三 ZSET Lua 原子更新；教职工创建 DTO `@Size`；邮箱正则方案 A + 域名校验 |
| 质量文档 | 测试数统一为 **286**（281 单测 + 5 FlowIT，`final-test-report.md`）；四域覆盖率 77.30/82.57/80.00/78.49；Lab1 日志换为 GitHub Actions 原始日志 |
