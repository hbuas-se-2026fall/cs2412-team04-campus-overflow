## 说明

**关于「无权限」的触发路径**：角色卡附表原写「未加入课程的学生打开课程内问题 → 没有查看权限」。
实测发现**当前后端 `QuestionQueryService.detail()` 不校验课程成员身份**——未加入课程的新注册用户
同样能看到课程内问题的完整内容（已用全新注册账号 `9116951` 验证）。
因此该状态在当时实现下**无法通过问题详情页触发**，本目录改用前端路由守卫 `RequireAdmin`
（`App.tsx:64`）产生的「无权限访问」页作为证据。

> 若产品要求「课程内问题仅成员可见」，需要后端在 `detail()` 增加 `identity.canManageCourse` 之外
> 的成员校验，并在前端补齐 403 分支——这是一个待确认的产品规则，建议在 v1.1 排期时明确。

> **【2026-11-28 勘误】** 上述"待确认的产品规则"已按 2026-11-25 审计 W-01 决策实现：
> `QuestionQueryService.detail()` 现校验课程成员身份并返回 403 QA-3006，前端 403 分支已补齐
> （见 `docs/qa/defects.md` Q-52 与 `docs/reports/v1-scope-decisions-2026-11-25.md`）。
